# MILK10 Skin Classifier

A study on the classification of clinical and dermoscopic images of skin pathologies, using the **MILK10** dataset.

> 🚧 **Work in progress.** This repository will be updated as the project develops.

## About

This project evaluates the performance of different convolutional neural network architectures (Inception, Xception, among others) for skin pathology classification, considering three scenarios:

1. **Dermoscopic** images only
2. **Clinical** images only
3. **Combined** dermoscopic + clinical images
